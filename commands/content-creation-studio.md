Start the Design Studio in the background and give me the link:

`python3 <skill>/scripts/studio.py studio`

Use the content-creation skill folder for `<skill>`. Do not run it in the foreground and do not wait on it. `studio.py studio --status` shows the link again; `--stop` ends it.
