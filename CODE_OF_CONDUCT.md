# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep feedback about the work, and make it easy for anyone to take part regardless of experience or background. Harassment, personal attacks and publishing others' private information are not tolerated.

Report unacceptable behaviour privately to the maintainer through a [GitHub security advisory](https://github.com/sarveshtalele/content-creation/security/advisories/new) or by direct message on GitHub. Reports are kept confidential.
