# 9 AI algorithms visualised

Part 1: the ideas, drawn simply. Supervised learning: Ridge Regression shrinks weights with an L2 penalty to reduce overfitting. Lasso Regression uses an L1 penalty to push some weights to zero, so some weights = 0.
Polynomial Regression adds powers of features to fit a curved relationship, a curved line through the data. Ensembles: Extra Trees combines trees built with random split thresholds, using random splits.
Unsupervised: Gaussian Mixture fits overlapping Gaussians with soft cluster membership. Deep learning: a Neural Network has layers of neurons that learn patterns from examples, learning from errors.
A Classifier separates two groups with a learned boundary, drawing a boundary. Q-Learning learns action values from the rewards it receives: act, reward, repeat.
A Diffusion Model generates samples by removing noise step by step, to remove noise. Algorithms are grouped as Supervised, Ensembles and Deep learning.

This post shows 9 AI algorithms visualised, one small diagram each.
