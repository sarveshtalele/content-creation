# The five floors of an AI app

An AI app is a building with five floors. Each floor does one job, and the roof shows what users see.

The top floor is the Interface, where people type and read answers. Below it sits the Assistant, which understands the request and plans the work.

The third floor is Tools, where the assistant searches, runs code and reads files. The fourth floor is Data, which stores documents and history.

The ground floor is Safety, with checks, limits and logs that keep every action under control.
