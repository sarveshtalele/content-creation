# Northwind Cloud at a glance

Northwind Cloud groups its services into four families: Compute, Storage, Data and Networking.

Compute runs your code. Northwind VM gives you full virtual machines, Northwind Functions runs short code on demand, and Northwind Containers runs packaged apps.

Storage keeps your files. Object Store holds files of any size, Block Volumes attach disks to machines, and Archive keeps rarely used data at the lowest cost.

Data keeps your records. SQL Database offers managed relational tables, Cache keeps hot data in memory for fast reads, and Search indexes text so you can find it quickly.

Networking connects everything. Load Balancer spreads traffic across servers, DNS maps names to addresses, and CDN serves content from locations close to users.

All services share one console, one billing account, and one set of access controls.
